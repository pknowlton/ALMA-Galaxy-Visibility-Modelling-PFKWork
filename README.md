# ALMA Visibility Modelling - Peter Knowlton
This repository in forked from Emily Carver's ALMA Visibility Modelling repository, with her original README below. This current 'msc-v2' branch will used nested sampling through the packaged [dynesty]. We will also explore the GPU capabilities of [galario] and generally clean up the modeling code. The older version that uses [emcee] for MCMC sampling is in the 'msc-v1-archive' branch.
